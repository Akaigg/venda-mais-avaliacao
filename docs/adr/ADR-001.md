# ADR-001: Estratégia de Ingestão de Dados

**Status:** Aceito  |  **Data:** 2026-04-07  |  **Autores:** Matheus Karpinski, Vitor Machado Blume, Rhuan José Voltolini, Marcelo Momm

## Contexto

A Plataforma precisa extrair diariamente dados incrementais do Sistema ERP e enviá-los para o Data Lake. 
Conforme o diagrama C4 Nível 2, o container "Ingestão de Dados" é o ponto de entrada do pipeline e deve executar de forma agendada, com baixo volume de dados, mínima manutenção e custo otimizado.

## Decisão

- Adotar **Azure Functions no modelo Serverless** como tecnologia para o container **Ingestão de Dados**. 
- A função será acionada por Timer Trigger, extrairá os dados do ERP e salvará os arquivos brutos no Azure Blob Storage.

## Consequências

- (+) Custo extremamente baixo
- (+) Zero gerenciamento de servidores ou infraestrutura
- (+) Escalabilidade automática e alta disponibilidade
- (+) Desenvolvimento rápido em Python
- (+) Monitoramento integrado com Application Insights

- (-) Possibilidade de cold start
- (-) Limite de 10 minutos por execução
- (-) Vendor lock-in com Azure Functions

## Alternativas rejeitadas

- Azure Virtual Machine; alto custo fixo e necessidade de gerenciamento contínuo de SO e patches
- Azure Container Instances; complexidade desnecessária para tarefa simples e agendada
- Azure Logic Apps; menor flexibilidade de código comparado ao Azure Functions Python
